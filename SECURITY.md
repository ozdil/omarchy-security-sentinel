# Security Policy

## Supported Versions

Only the latest stable release on Omarchy Linux is actively supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| latest  | :white_check_mark: |
| < latest| :x:                |

## Reporting a Vulnerability

We take the security of Omarchy Linux and its plugin ecosystem very seriously.

If you believe you have found a security vulnerability in this project:

1. **Private Vulnerability Reporting**: Please use the private vulnerability reporting feature on GitHub Security Advisories for this repository.
2. **Direct Contact**: Alternatively, contact the maintainer directly via email: `ozan@ozanozdil.com` or via security dispatches on `https://ozanozdil.com`.
3. **Disclosure Policy**: Please allow up to 48 hours for an acknowledgment and coordinated disclosure before any public disclosure.

Zero-trust principles, process group sandboxing, and strict memory limits are actively enforced across all Omarchy components.
